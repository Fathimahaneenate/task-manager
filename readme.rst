 Task Manager Project (CodeIgniter)

 About Project
This is a Task Manager web application built using CodeIgniter PHP framework. It helps users manage daily tasks with features like priority, status, filtering, and sorting.



 Features
- Add tasks with title, due date, and priority
- Mark tasks as completed
- Delete tasks
- Filter tasks (All / Pending / Completed)
- Sort by due date and priority
- Highlight tasks due within 24 hours
- Prevent past date task entry
- Bootstrap UI design
- Session flash messages for validation



Tech Stack
- PHP (CodeIgniter Framework)
- MySQL
- Bootstrap 5
- HTML / CSS



  Highlights
- Clean MVC architecture
- Time-based task urgency system
- Professional UI design
