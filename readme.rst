 Task Manager (CodeIgniter PHP)

 Project Overview
This is a simple Task Manager web application built using CodeIgniter framework. It helps users manage tasks with priority, status, filtering, and time-based urgency highlighting.

---

 Features
- Add tasks with title, due date, and priority
- Mark tasks as completed
- Delete tasks
- Filter tasks (All / Pending / Completed)
- Sort tasks by due date and priority
- Highlight tasks due within 24 hours
- Prevent adding past date tasks
- Flash messages for validation errors
- Clean Bootstrap UI

---

 Tech Stack
- PHP (CodeIgniter Framework)
- MySQL
- Bootstrap 5
- HTML / CSS

---

 Features Highlights
- 🔴 Urgent tasks highlight (24 hours rule)
- 📊 Sorting & filtering system
- ⚡ Simple and clean UI
